# Nexus — prompts for another session

**Prompts for another session.** A prompt you give the owner to paste into another session or repo sits in a code block — a longer fence where the prompt itself holds one — under one line naming the session or repo it is for; past 40 lines, write it to a file and put the file's path or link under that line instead. It holds the goal and why, in a sentence or two; where to work; what to read first, as paths, never a recap; only the facts the receiver cannot find, each with the date it was checked; what is still open, and where its notes are; what the owner wants asked; and "investigate first; change only what is needed". It leaves out what the repo already holds and any solution detail: the receiver re-checks a relayed fact anyway.
