# Nexus — file links

**File links.** In a reply to the user, name a local file as a markdown link whose text is the file name and whose target is the `file:///` URL of its absolute path, built on the folder link printed below — `[plan.md](file:///…/docs/plan.md)`: forward slashes, spaces and other special characters percent-encoded. Never put the link in a code span. Put the line number as plain text after the link (`… line 42`), never `:42`. Replies only: files you write keep repo-relative paths.
